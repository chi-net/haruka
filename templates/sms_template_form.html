返回模板

本功能只创建账本记录，不接入银行或发起支付。转入／转出永远等待手动确认；只有明确选择收入／支出动作才自动生成普通账单。审计动作不改变账户余额。

自定义模板优先于内置招商银行模板；多个模板同时匹配会报错。编辑或删除模板不会改写已有候选的匹配快照。停用模板仍可预览，但不会用于实际接收。

可直接使用的预设

点击仅填写下面的草稿与样例，不保存、不接收短信、不记账。请核对实际短信格式；转账／快捷支付需选择短信所属账户。招商银行定投可不绑定计划，使用尾号与基金名称匹配现有短信实扣计划。

至少填写发送号码或银行标记之一；发送号码精确匹配，银行标记匹配短信任意位置的【标记】。同时填写必须全部满足（AND）。这些条件不是身份认证，API 仍需 Bearer 令牌。

最多 4096 字节，匹配原始短信。使用 Rust 安全正则，不支持前后查找（lookaround）或反向引用；建议用 ^ 和 $ 限定整条短信。

转出时是转出账户，转入时是转入账户；另一账户在短信页手动选择且必须同币种。信用账户转出只可使用已有正余额，不能借款转账。

只可选择启用中的短信实扣计划。不绑定时必须提取 last4 和 fund（或用 content 作为基金名）；绑定时如提取了 last4／fund，仍须与计划一致。

只展示与动作一致的分类。自动账单按所选账户币种记账；食品属性沿用所选分类。余额不足或关联项被删除会明确报错，不生成账单。

取消

命名捕获帮助

  • (?P<amount>[0-9]+(?:\.[0-9]{1,2})?) 提取金额，以元为单位输入，内部为整数分。金额必须大于 0；支持规范千分位如 1,234.56。定投成功、转账、收入／支出需要 amount。
  • (?P<content>.+?) 提取备注／收款人／失败原因；(?P<fund>.+?) 提取基金名。除仅审计以外需相应的 content 或 fund。不要把整个短信命名为 amount。
  • (?P<last4>[0-9]{4}) 提取四位账户尾号；可选的 balance 提取非负余额。仅审计可不提取金额或内容。
  • 可选时间字段：year、month＋day、hour＋minute。月日／时分须成对，提取的日期时间必须与 API time 的北京时间一致；不提取日期则使用 API 时间。
可复制的通用金额与内容表达式
^【示例银行】金额(?P<amount>[0-9]+(?:\.[0-9]{1,2})?)元，内容：(?P<content>.+?)[。.]?$

样例：来源号码 95500，短信「【示例银行】金额12.34元，内容：午餐。」；先用仅审计预览，再自行明确选择所需动作。

不落盘预览

仅用当前草稿提取字段，不保存模板或样例，不调用短信接收 API，不创建审计记录、账单或转账。必要关联项仍需有效选择；此预览不会执行余额变动，也不验证其他模板是否同时匹配。
